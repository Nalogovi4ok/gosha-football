# Футболистые — картотека лучших футболистов

Учебный проект Гоши (8 лет): статический сайт-справочник о великих футболистах —
от Пеле и Марадоны до Ямаля и Мбаппе.

Технологии: HTML + CSS + JavaScript (без фреймворков).
Фото: Wikimedia Commons, свободные лицензии.

## Структура
- `index.html` — главная: hero-экран, вкладки сортировки (А–Я, по клубам, по позициям), поиск
- `player.html` — страница игрока (открывается по ссылке `player.html?id=messi`)
- `data.js` — данные игроков и фото
- `photos/` — фотографии игроков
